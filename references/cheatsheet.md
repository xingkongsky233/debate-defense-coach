# 决策规则速查 — 诡辩与反驳

| 能力 | 一句话规则 |
|---|---|
| 论辩攻防助手（诡辩识别×反驳方法） | 遇到任何"不对劲的话"，先识别诡辩类型，再选反驳武器 |
| 诡辩识别双特征模型 | 目的+手段双特征命中即按诡辩处理，不纠缠表面言辞 |
| 复杂问语识别与破解 | 问句拆两层：表层问题+深层预设；预设未确认就不正面作答，先拆预设 |
| 论据质量三条件总则（真实+相关+充分） | 任何论证做安检：论据真实吗？相关吗？充分吗？三问不过即不成立 |
| 人身攻击与情绪话术免疫 | 标记越界→拒绝接话→拉回论题；只反驳观点不评价人 |
| 以矛攻盾（自相矛盾揭露） | 收集对方前后言论→整体分析→对举矛盾两方，让其无法自圆 |
| 二难法（双角假定引申） | 找论题的二分对立→两侧假定引申→逼出对方无法接受的结论 |
| 归谬法（假设-引申-暴露） | 假设对方观点成立→循其逻辑引申出更荒谬的结论→荒谬自行现形 |
| 论辩实战陪练（Socratic Sparring） | 五幕陪练：开局（场景/难度/手法）→AI出招→你接招→5维判卷→复盘升级 |
| 论证-推理二分审查标准 | 先判性质（说服他人=论证/自我探索=推理），再选审查严度 |
| 以实辨言（事实裁定语言争议） | 两词是否同义？把各自映射到事实，指向同一事实即同一 |
| 语境限定核查（含断章取义防御） | 语境三层：物的类/事的范围/语言背景，越界即歪曲 |
| 概念同一性守卫 | 词形没变但所指变了=偷换概念；三段论先查中项 |
| 论题同一性守卫 | 锁死中心命题，防‘近似跑题‘：形式变/语气变/歧义引新义 |
| 矛盾扫描（言悖/言实悖） | 两条扫描线：对象矛盾+判定vs陈述矛盾，重点收‘说漏的反向细节‘ |
| 排中律检验（回避识别） | 先证二分，再逼表态：非此即彼处不得双双否认 |
| 论据真实性审查 | 论据真理从哪来？独立可验还是绕回论题/主观之见/捏造 |
| 论据相关性审查 | 即使论据全真，结论必然成立吗？有别的解释吗？ |
| 论据充分性审查（覆盖面检验） | 证据范围 vs 论题范围：证据<论题则结论降级为‘仅对已知样本成立‘ |
| 权威相对性检查 | 三查：领域匹配/时空有效/论证可替换；防伪造权威 |
| 情理分离检验 | 对方给的是理由还是情绪？热起来时暂停，回理智提问 |
| 类推与比喻有效性检查 | 类推两问：有联系吗？是实质/原理性联系吗？比喻抽掉后独立论据在哪 |
| 揭露混淆-区别法 | 不吵不绕，把混淆双方并排拆开指出差异 |
| 转移法（借题而发） | 借对方语句形式构造相反论题作答——只做形式转移，实质必须揭谬 |
| 言辞为术（语言功能反用） | 借等义/多义/特殊化/模糊四属性改编对方原句，保持语言关联使其无法抵赖 |
| 剖析法（分而治之） | 先分后总：拆层→是非/利害/实质/后果四线逐点论→驳倒整体 |
| 比较法（对举显差） | 不抽象辩护，拉出对方无法否认的参照物并排对照 |
| 类推反驳 | 找事理相同且为对方熟知的同类事例，类推显其谬 |
| 喻法反驳 | 编对方必须承认的场景引导其自投结论；只求理真不求事真 |
| 实证法（以事实驳斥） | 事实反驳分层：实事实须确凿、虚事实求理真；对方熟知才有效 |
| 行为反驳 | 言语说不服就当场做给他看/抓他行为作据/设计情境诱其自证 |
| 真相反驳 | 不逐条解释，披露可自证的完整真相让谬论自行塌陷 |
| 驳迷信权威 | 三路反击：权威服从真理/追问来源链/抬出更高标准 |
| 以谬治谬（以其人之道还治其人之身） | 借对方荒谬逻辑反向套回；手法须与对方同构，两用：制胜/惩罚 |
| 论证防御性自查清单 | 发言前自查：概念同一？论题锁定？论据真实相关充分？不转人身？ |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
