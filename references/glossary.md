# 《诡辩与反驳》术语词典 (GLOSSARY)

> 全库共享术语。作者用法与常识有差异的条目是重点（key_distinction 段），下游能力卡引用术语时以本词典为准。

| 术语 | 一句话定义 | 与常识用法的关键差异 |
|---|---|---|
| 诡辩 | 诡辩是有意识地违反逻辑规律，是'明知故犯'、'别有用心'。其突出特征有二：1.服务于某种需要和目的。2.往往要借助某种诡辩手段。其结果，常可'胜人之口'，但不能 | ≠ 常识把"诡辩"当贬义泛指"强词夺理/不讲理地狡辩"。 |
| 论证 | 论证是以已知论据证明已知论题，是于人际间进行的交流活动，是以说服、制胜他人为目的的，因此，总要形诸语言。 | ≠ 常识把"论证"当"道理推理/证明自己的主张"的泛称。 |
| 推理 | 推理是由已知前提推想未知结论，是于头脑中进行的探索性的思维活动，是以自己获取结论为目的的，一般并不形诸语言。 | ≠ 常识把"推理"与"论证"混用（日常说"你的推理站不住脚"）。 |
| 论题 | 任一辩论过程都有一个中心论题，即焦点。对中心论题论证的完成，可以视为一个辩论过程的结束。""论题只能有一个，而且必须有一个。 | ≠ 常识把"论题"当"讨论的话题/主题"（可说"今天论题很多"）。 |
| 语境 | 任何辩论都是在一定时空条件下进行的，这种背景条件，可称为'语境'。语境是客观存在，是辩论双方所明了、所承认、心照不宣、自觉遵循的。""物的类是一种语境……这个类 | ≠ 常识（语言学的）"语境"指语言上下文/说话环境。 |
| 以言乱实（含对义：因言乱实） | 弄不清'言'与'实'之间的这种关系，往往会因不解'言'之意义而弄错了事实，这就是'因言乱实'。如果利用言与实之间的错综关系来惑乱人们对事实的认识，就是'以言乱实 | ≠ 常识没有这对术语。 |
| 偷换概念 | 在辩论过程中，将一个概念更换成另一个与其自身不一致的概念，是一种逻辑错误。""这种更换大都采取隐蔽的方式，即，更换概念而不改变语词形式，给人以并未更换的假象。因 | ≠ 常识说"偷换概念"泛指"擅自改变某词的意思"（口语用）。 |
| 中项 | '鲸'在两个前提间起到了联接、媒介的作用，充当了'中间人'的角色，所以，三段论理论中，称之为'中项'。中项是包含在两个前提中的相同的项，它在三段论前提中要出现两 | ≠ 常识一般只在三段论教材里遇到"中项"（middle term），多指"在结论中不出现代名词"。 |
| 四概念（错误） | 一个三段论中本应有三个概念，由于中项两次使用是两个不同的概念，所以，就出现了四个概念，因此，这种错误又称为'四概念'错误。""'四概念'错误是偷换概念的一种特殊 | ≠ 常识无此术语。 |
| 转移论题 | 在一个辩论过程中，将一个论题转到另一个论题，先后出现不同的论题，则是常见的一种错误，即'转移论题'。""同是'转移论题'，在辩论中的表现并不相同。有'自身转移' | ≠ 常识说"跑题/离题"，不区分转移方向。 |
| 言悖 | '言'，指陈述的论题；'悖'，矛盾。'言悖'，指所陈述的论题存在着矛盾。""亚里士多德说过：'一切信条中最无可争议的就是：相反叙述不能同时两都真实。''相反叙述 | ≠ 常识说"自相矛盾"，不区分矛盾所在层面。 |
| 言实悖 | '言实悖'是人们对事实的判定与对事实的陈述发生了矛盾。""'言'是指对有关事实的断定，实际就是论题。'实'是对有关事实的陈述。""这一事实未必是客观的真实存在， | ≠ "主客观不符"（如"太阳是不发光的"只说明主观认识错了，不属思维错误）。 |
| 回避 | 面对针锋相对的'是'与'非'的情况，双双予以否认，而去寻求其他可能，这实际是一种'回避'。'回避'也是一种诡辩手法。""亚里士多德说：'在相反叙述之间也不能有间 | ≠ 常识把"回避"当"躲闪/避而不答"的泛指。 |
| 复杂问语 | 这种问语含有并不确凿的预先设定的事实，可称为'复杂问语'。""'复杂问语'中包含的事实大多是问者所期望存在的，甚至是强加于人的，使之包含在问语深层，目的是借表层 | ≠ 常识无此术语，易与"诱导性提问"混同（诱导在于引导答案方向）。 |
| 简单问语 | '简单问语'层次单一，一般不具有修辞意义，因为其间没有施用任何修辞手段；同时，也不具有逻辑意义，因为它未断定任何客观情况，并不反映任何确凿的存在。 | = 与复杂问语相对照的对义术语：无预设、无断定、单层次的正常问句（"你受过惩罚吗？"）。 |
| 先验理由 | '先验理由'是一味地以未经事实检验的主观之见作依据去进行推论、证明。'先验'指先于事实，先于经验。 | ≠ 常识/哲学"先验论证"（transcendental argument，康德脉络）或"先入为主"。 |
| 以偏概全 | 维诺格拉多夫对'以偏概全'错误的解释是：'把只有在某一点、在一定的条件下才是可靠的论据，引证了来作为论题之绝对的、在所有条件下都可靠的论据'。简言之，是以片面的 | ≠ 常识"管中窥豹/一叶障目"（偏颇但不精确）。 |
| 强词夺理 | '强词夺理'是无效推论的一个泛称。所有各种形式的无效推论都可称为'强词夺理'。""'强词夺理'总的特点是缺乏论证性，即不能以正确的方法和真实的论据将论题加以证明 | ≠ 常识把"强词夺理"当"不讲理地硬辩"的通用骂名。 |
| 转移法（反驳方法） | 有时，在反驳他人荒谬论题时，故意将其转移，既不是由于思维混乱，也不是出于某种不良目的，而是因某种合理需要。这种'转移'，不但不能简单地斥为错误，而且完全可以看作 | ≠ 上篇"转移论题"（g10）：同叫"转移"，一个是诡辩错误，一个是合法反驳 — 这是全书最易混淆的一对。 |
| 以矛攻盾 | 将矛盾着的两方揭示出来，以其矛，攻其盾，使论敌因无法自圆其说而陷入窘境，这就是'以矛攻盾'的方法。 | ≠ 成语"自相矛盾/以子之矛攻子之盾"只指指认矛盾。 |
| 二难法 | 对这种论题，可以从两个不同角度进行假定，而后加以引申，导致出论敌无法接受的结论，使论敌陷入无法解脱的进退两难的境地，这种方法，叫做'二难法'。 | ≠ 常识"进退两难/两难困境"只在描述困境状态。 |
| 剖析 | 对荒谬论题所论及的事物情况，先进行分解，然后就一点或几点分别加以论述，这就是'剖析'。""'剖析'所及是某些方面、某些因素，其最终目的是驳倒整个荒谬论题，就过程 | = 作者定义：分而治之——把论题涉及的事物分解成几方面，逐点论述，最终整体驳倒。 |
| 实证 | 维诺格拉多夫说：'驳斥对方所提出的论题的最可靠最有效的方法，是用事实来驳斥的方法。'""以事实来驳斥的方法，就是'实证'的方法。""事实泛指各种形式的客观存在， | ≠ 常识/方法论"实证研究"（empirical research）指大样本数据验证。 |
| 归谬 | 先假设荒谬之说成立，而后，以之为依据，循着'有此必有彼'的关系，引申出一个更为明显荒谬的说法，使人一望而知，使荒谬论题暴露无遗，这就是个'归谬'的过程。""'归 | ≠ 常识"归谬法"="假设对方对推出荒谬"（只保留最粗的骨架）。 |
| 以谬治谬 | '以谬治谬'是用与论敌同样荒谬的论题去予以回击。""它只是不直接针对论题，而是让论敌切身感受其论题的荒谬。'以谬治谬'重在'治'，不在'驳'，是以'治'达到'驳 | ≠ 常识"以其人之道还治其人之身/以毒攻毒"（泛指反制）。 |

## 逐条详注

### 诡辩  <sub>(序)</sub>

**作者定义**:

"诡辩是有意识地违反逻辑规律，是'明知故犯'、'别有用心'。其突出特征有二：1.服务于某种需要和目的。2.往往要借助某种诡辩手段。其结果，常可'胜人之口'，但不能'服人之心'。"

**与常识用法的差异**:

≠ 常识把"诡辩"当贬义泛指"强词夺理/不讲理地狡辩"。 = 作者限定为"论证过程中的有意违规"，三要素缺一不可：①违反逻辑规律 ②有意识（明知故犯）③服务于某种目的（别有用心）。 ≠ "因言乱实"式谬误 — 那是无知/无意之失，属谬误而非诡辩；定义在同一章把二者严格切割："因言乱实是一种谬误，以言乱实就属诡辩了"。 = 判据是动机+手段的耦合：只看表面言论无法区分诡辩与谬误，须问"是否有意+是否为目的"。

**为什么下游需要**:

全书的宿主概念。下游"诡辩识别总入口"的第一个分类问题是"这是无意谬误还是有意诡辩"， 若沿用常识义（凡狡辩皆诡辩），会把无害的口误/思维粗疏误判为恶意攻击。

---

### 论证  <sub>(序)</sub>

**作者定义**:

"论证是以已知论据证明已知论题，是于人际间进行的交流活动，是以说服、制胜他人为目的的，因此，总要形诸语言。"

**与常识用法的差异**:

≠ 常识把"论证"当"道理推理/证明自己的主张"的泛称。 = 作者与"推理"精确二分：论证是人际间的交流活动（说服他人）、以已知论据证明已知论题、必形诸语言。 = 诡辩只出现在论证过程，不发生在推理过程 — 推理是给自己用的，论证是给别人用的，逻辑错误的归属因场景而异。

**为什么下游需要**:

决定下游 skill 的应用边界：识别诡辩/反驳对手只发生在"论证"场景（对话、演讲、文章）。 错把推理当论证，会把"一个人内心的思维探索"也纳入诡辩审查，制造误伤。

---

### 推理  <sub>(序)</sub>

**作者定义**:

"推理是由已知前提推想未知结论，是于头脑中进行的探索性的思维活动，是以自己获取结论为目的的，一般并不形诸语言。"

**与常识用法的差异**:

≠ 常识把"推理"与"论证"混用（日常说"你的推理站不住脚"）。 = 作者限定推理为头脑内探索：目的在"自己获取结论"，不形诸语言；论证在人际间，目的在"说服别人"，必形诸语言。 = 推论类诡辩（强为因果、或然推论、无关推论）虽然借推理形式出现，但因"讲给别人听、为了服人"，仍属论证范畴的诡辩。

**为什么下游需要**:

防止下游 skill 把范围无限扩大：不要求审查"用户内心怎么想"，只审查"说出口/写出来的论证"。同时帮助定位"诡辩"与"思维谬误"的分界。

---

### 论题  <sub>(八、转移论题)</sub>

**作者定义**:

"任一辩论过程都有一个中心论题，即焦点。对中心论题论证的完成，可以视为一个辩论过程的结束。""论题只能有一个，而且必须有一个。"

**与常识用法的差异**:

≠ 常识把"论题"当"讨论的话题/主题"（可说"今天论题很多"）。 = 作者强调论证纪律：一个论证过程只能有一个论题，且必须贯串始终；中途更换即"偷换论题/转移论题"错误。 = 论题是论证的"宪法"：概念不得偷换、论题不得偷移、断定不得自相矛盾，都与论题同一性相关。

**为什么下游需要**:

"论题同一性守卫"skill 的基准点。没有"唯一论题"的概念，就无法判定"转移论题/偷换论题"， 也无法在下篇"转移法"与上篇"转移论题"之间做正误区分（前者合法反驳，后者非法诡辩）。

---

### 语境  <sub>(三、歪曲语境)</sub>

**作者定义**:

"任何辩论都是在一定时空条件下进行的，这种背景条件，可称为'语境'。语境是客观存在，是辩论双方所明了、所承认、心照不宣、自觉遵循的。""物的类是一种语境……这个类，便是设定的语境，辩论双方的议论都必须限于这个类的范围而不能越出。"

**与常识用法的差异**:

≠ 常识（语言学的）"语境"指语言上下文/说话环境。 = 作者扩展为辩论的背景条件，明确包含"物的类"（事物所属的类别限定）这一非语言语境 —   例：问"在人的口腔里最后出现的是什么牙齿"，答"假牙"即越出"自然生长牙齿"这类。 = 歪曲语境 = 故意越出给定的类/范围作答，且常"取其形式不变，而将内容歪曲"（借语言形式因素）。

**为什么下游需要**:

识别"答非所问/越类作答"类诡辩（如死狼对活狼、假牙对真牙）的判据。 下游"诡辩识别"需能把"语境"当参数检查：给定类是什么？对方是否越出？

---

### 以言乱实（含对义：因言乱实）  <sub>(二、以言乱实)</sub>

**作者定义**:

"弄不清'言'与'实'之间的这种关系，往往会因不解'言'之意义而弄错了事实，这就是'因言乱实'。如果利用言与实之间的错综关系来惑乱人们对事实的认识，就是'以言乱实'。'因言乱实'是一种谬误，'以言乱实'就属诡辩了。"

**与常识用法的差异**:

≠ 常识没有这对术语。 = "言/实"的关系是本书特有的分析框架：语言有等义性（半空桶=半满桶）与多义性（杜鹃=鸟/花），言实之间并非简单对应。 = 同一现象两种定性：无意不解 → 因言乱实（谬误）；有意利用 → 以言乱实（诡辩）。 = 鉴别方法在"实"不在"言"："只有'实'，才能辨'言'"，语言分析无济于事时靠事实判断。

**为什么下游需要**:

这是"语言类诡辩"的总纲，上篇三、以言乱实的变体（断句多义、略称多义、曲解词义）都以它为基础。 下游识别"偷换语义/玩弄措辞"时必须先建立"言实对应关系"检查。

---

### 偷换概念  <sub>(四、偷换概念)</sub>

**作者定义**:

"在辩论过程中，将一个概念更换成另一个与其自身不一致的概念，是一种逻辑错误。""这种更换大都采取隐蔽的方式，即，更换概念而不改变语词形式，给人以并未更换的假象。因此，可称为'偷换'。"

**与常识用法的差异**:

≠ 常识说"偷换概念"泛指"擅自改变某词的意思"（口语用）。 = 作者的技术判据：**语词形式不变**（同一个词），概念却变了（利用一词多义/歧义/相似对象），   例："烫头"由"美发"偷换为"被烫"；"讲话"由"干扰性说话"偷换为"开口说话"。 = 更换概念的两个来源：语词与概念不对等（一词多概念）、概念反映的对象相似（类人猿vs猴子）。 = 仅"改变词义"而无语词同一性作掩护者不叫偷换。

**为什么下游需要**:

"概念同一性守卫"的主武器。判定步骤固定：①取语词②查辩论前后两次内涵③不同则指认偷换。 它必须与 g04 论题同一性区别使用 — 概念层 vs 命题层。

---

### 中项  <sub>(五、四概念)</sub>

**作者定义**:

"'鲸'在两个前提间起到了联接、媒介的作用，充当了'中间人'的角色，所以，三段论理论中，称之为'中项'。中项是包含在两个前提中的相同的项，它在三段论前提中要出现两次。""要使中项起到应有的作用，其自身必须始终保持同一性，即，在前提中两次使用必须是一个概念，而不能更换。"

**与常识用法的差异**:

≠ 常识一般只在三段论教材里遇到"中项"（middle term），多指"在结论中不出现代名词"。 = 作者强调中项的功能角色：联接两个前提的"中间人/媒介"，且是"四概念"错误的唯一发生点 —   中项两次使用若为两个不同概念 → 三段论出现四概念 → 推理无效。 = 检查口诀：中项两次出现，两次必须同义，即总体/个体、统称、多义词均可导致中项偷换。

**为什么下游需要**:

三段论式诡辩的检测锚点。教用户检查"中间那个词在大小前提里是不是同一个概念"， 例：欧布利德"未失掉的东西犹在→你未失掉犄角→你有犄角"即中项范围被偷换。

---

### 四概念（错误）  <sub>(五、四概念)</sub>

**作者定义**:

"一个三段论中本应有三个概念，由于中项两次使用是两个不同的概念，所以，就出现了四个概念，因此，这种错误又称为'四概念'错误。""'四概念'错误是偷换概念的一种特殊表现。与一般偷换概念错误所不同的是，它仅出现于三段论推理之中。"

**与常识用法的差异**:

≠ 常识无此术语。 = "偷换概念"的特化形态：仅出现于三段论中；一般偷换概念不限三段论。 = 判定标准：三段论含三个"项"，其中中项两次使用若不同概念，则名义三概念、实质四概念。 = 常见原因（原文列举）：总体与个体、简称/统称、多义词各义项、整体与部分、范围大小不同。

**为什么下游需要**:

三段论诡辩（如"书是知识的海洋"式）的唯一诊断标签。下游识别偷换概念时， 若现场出现"前提1—前提2—结论"的结构，就该检查是否落入四概念。

### 转移论题  <sub>(八、转移论题)</sub>

**作者定义**:

"在一个辩论过程中，将一个论题转到另一个论题，先后出现不同的论题，则是常见的一种错误，即'转移论题'。""同是'转移论题'，在辩论中的表现并不相同。有'自身转移'与'问答转移'之别。"

**与常识用法的差异**:

≠ 常识说"跑题/离题"，不区分转移方向。 = 作者细分两种：   ①自身转移：陈述者自己把论题换了（江青从"法家爱国"转到"欧洲科学受中国启发"）。   ②问答转移：以"答非所问"为最多见表现；问者转移较少。 = 与"偷换论题"的关系：偷换论题利用语义歧义暗中换命题；转移论题是明显把焦点换掉，常以"相似相近"造成"只有一个论题"的假象。 ≠ 下篇"转移法"：那是合法反驳，故意作形式转移以揭露对方荒谬，须与上篇此错误对照区分。

**为什么下游需要**:

会议主持人/辩手必备。给出两条实用指令：①盯住中心论题不放松②被转移时公开指认"你换了论题"。 与"转移法"的正误对照是全书最精巧的区分点之一。

### 言悖  <sub>(九、言悖)</sub>

**作者定义**:

"'言'，指陈述的论题；'悖'，矛盾。'言悖'，指所陈述的论题存在着矛盾。""亚里士多德说过：'一切信条中最无可争议的就是：相反叙述不能同时两都真实。''相反叙述同时两都真实'就是'言悖'。"

**与常识用法的差异**:

≠ 常识说"自相矛盾"，不区分矛盾所在层面。 = 作者限定为**论题自身的矛盾**（逻辑矛盾）：对同一对象/事态作出不相容的断定，可表现为对"物"（老孙头说瞎马是最好的马又说是破马）或对"事"（毛拉先说女人的话别听又说有时可听）。 = 重要：两种矛盾断定不一定都公开，可"一显一隐"（皮卡索夫坚称"没有信念这回事"却有自己的信念）— 隐蔽形态更难识别。 = 与"言实悖"对照：言悖是论题内部自相冲突；言实悖是"判定"与"陈述的事实"冲突（见 g12）。

**为什么下游需要**:

自相矛盾检测的第一种子类型。识别技法："把对方先后两次断定并置对举" — 这也是下篇"以矛攻盾"（g20）的准备动作。

---

### 言实悖  <sub>(十、言实悖)</sub>

**作者定义**:

"'言实悖'是人们对事实的判定与对事实的陈述发生了矛盾。""'言'是指对有关事实的断定，实际就是论题。'实'是对有关事实的陈述。""这一事实未必是客观的真实存在，它只是辩论者陈述中的事实……'言实悖'是在思维过程中，人们自身出现的矛盾。"

**与常识用法的差异**:

≠ "主客观不符"（如"太阳是不发光的"只说明主观认识错了，不属思维错误）。 = 言实悖是思维过程内部矛盾：判定（言）与陈述的事实（实）冲突 —   例：营业员说"上装是最新式"（言）却陈述"在橱窗里挂了三年"（实）。 = "实"的特殊性：不要求是客观真实存在，可以是"随口说出来的事实"甚至"即兴行为" —   行为时"言""实"相悖变成"言行相悖"（乙举手机辩"有意动作无目的"）。 = 关键机制：真话多因疏忽/被迫而泄漏，故"言实悖"常被用作识谎突破口。

**为什么下游需要**:

识谎/审问类 skill 的核心抓手：对方立场（言）与他顺口陈述的事实（实）打架即破绽。 场景：警察审问、质问、追问——"你说是偶犯，却五年多次购买"。

---

### 回避  <sub>(十一、回避)</sub>

**作者定义**:

"面对针锋相对的'是'与'非'的情况，双双予以否认，而去寻求其他可能，这实际是一种'回避'。'回避'也是一种诡辩手法。""亚里士多德说：'在相反叙述之间也不能有间体……'""企图将两种仅有的可能都予以否认，以寻求中间情况，是错误的。"

**与常识用法的差异**:

≠ 常识把"回避"当"躲闪/避而不答"的泛指。 = 作者技术化为违反排中律的特定形态：对非此即彼的两种仅有可能**双双否认**或**寻找中间情况** —   例：贪污与不贪污之间不存在第三态；庄子"处乎材与不材之间"。 = 变体：①公开双双否认（丁否认"先有鸡/先有蛋"都错）②不置可否、躲躲闪闪（汉弗莱"既不能说又不能不说"）③以无关话搪塞（张乔治借钱）。

**为什么下游需要**:

检测"打太极/和稀泥"话术的精准判据：当事物只能二选一时，对方是否拒绝二选一？ 适用于职场套话、采访、法庭问询等强问答场景。

---

### 复杂问语  <sub>(十二、复杂问语)</sub>

**作者定义**:

"这种问语含有并不确凿的预先设定的事实，可称为'复杂问语'。""'复杂问语'中包含的事实大多是问者所期望存在的，甚至是强加于人的，使之包含在问语深层，目的是借表层语义的迷惑作用，使答者于疏忽之中承认这一事实。""复杂问语"不仅可以预设事实，而且可以预设观点。

**与常识用法的差异**:

≠ 常识无此术语，易与"诱导性提问"混同（诱导在于引导答案方向）。 = 复杂问语的结构=表层单层问句+深层预断（预设事实或观点）；   判据：答"是/否/何时"任何一层都会默认承认预设。 = 经典例：黑格尔引梅内德谟"你是否已停止打你父亲？" 答是与否都认罪；答"我既没停止也没打他"才是破法。 = 破解核心：不答表层，先否定预设（霍苏埃："不是被害人，这是意外事故"）。

**为什么下游需要**:

高危陷阱检测专项（审问、媒体采访、职场套话）。给出可直接执行的破法模板： "拒绝作答+点破预设"，并提示预设可以是"事实"也可以是"观点"。

---

### 简单问语  <sub>(十二、复杂问语)</sub>

**作者定义**:

"'简单问语'层次单一，一般不具有修辞意义，因为其间没有施用任何修辞手段；同时，也不具有逻辑意义，因为它未断定任何客观情况，并不反映任何确凿的存在。"

**与常识用法的差异**:

= 与复杂问语相对照的对义术语：无预设、无断定、单层次的正常问句（"你受过惩罚吗？"）。 = 判定一个问句是否简单问语取决于语境：问者确知事实则单层；故意装作不知或事实不存在则复杂化。 = 简单问语→可如实作答；复杂问语→先破预设再答。

**为什么下游需要**:

作为对照组，防止"把所有问句都当陷阱"的过度防御。 下游 skill 需先判"层数"，再决定应答策略。

---

### 先验理由  <sub>(十四、先验理由)</sub>

**作者定义**:

"'先验理由'是一味地以未经事实检验的主观之见作依据去进行推论、证明。'先验'指先于事实，先于经验。"

**与常识用法的差异**:

≠ 常识/哲学"先验论证"（transcendental argument，康德脉络）或"先入为主"。 = 作者定义：以未经事实检验的主观之见（预感、荒谬信条、迷信理论）作论据来论证。 = 特殊机制：先有结论再去"套"事实，用被曲解的事实反证先验之见 —   "亡铁者"看邻居之子无不似窃铁者；伊凡·伊凡诺维奇把邻居日常燃火解释为阴谋凭据。 = 论据类诡辩：违背"论据必须真实"的第一要求（真实论据=可经验验证）。

**为什么下游需要**:

"论据质量审核"三维检查（真实/相关/充分）中的"真实"维度的反面教材。 帮助识别"先下定论再找印证"的确认偏误式话术。

### 以偏概全  <sub>(十五、以偏概全)</sub>

**作者定义**:

"维诺格拉多夫对'以偏概全'错误的解释是：'把只有在某一点、在一定的条件下才是可靠的论据，引证了来作为论题之绝对的、在所有条件下都可靠的论据'。简言之，是以片面的事实论据证明关于全面事实的论题。"

**与常识用法的差异**:

≠ 常识"管中窥豹/一叶障目"（偏颇但不精确）。 = 技术判据：论据的"可靠条件"（某点/某条件下）与论题的"适用范围"（一切条件）不匹配 —   用狭隘个人体验推天下（小人国哲学家；李载仁以猪肉惩罚人）。 = 归属论据类：事实本身真，但"运用不当"（范围放大）→ 与"谬论为据/假象为据"区分：后者是论据本身假。

**为什么下游需要**:

"论据质量审核"之"充分性"维度的核心错误。 检查提问：论据覆盖了论题的全部情况吗？是否只覆盖了一个角落就作全称结论？

---

### 强词夺理  <sub>(二十五、强词夺理)</sub>

**作者定义**:

"'强词夺理'是无效推论的一个泛称。所有各种形式的无效推论都可称为'强词夺理'。""'强词夺理'总的特点是缺乏论证性，即不能以正确的方法和真实的论据将论题加以证明。"

**与常识用法的差异**:

≠ 常识把"强词夺理"当"不讲理地硬辩"的通用骂名。 = 作者给了精确地位：它是**推论类诡辩的兜底类别**——凡无效推论（以偏概全、理由不足、无关推论、或然推论等）皆属之，   另有"不特属某一类型"的特殊表现（以惑人言辞文过饰非、择其一点不及其余）。 = 核心判据：缺乏论证性 = 不能用"正确方法+真实论据"证明论题（教师答"同一只猫"、医生确诊"老病又犯"）。

**为什么下游需要**:

诡辩识别总入口的"未分类兜底"：当推论类诡辩无法套进其他具体标签时，一律归入强词夺理。 避免因"叫不出名字"而放过对方。

### 转移法（反驳方法）  <sub>(下篇·二、转移法)</sub>

**作者定义**:

"有时，在反驳他人荒谬论题时，故意将其转移，既不是由于思维混乱，也不是出于某种不良目的，而是因某种合理需要。这种'转移'，不但不能简单地斥为错误，而且完全可以看作是一种巧妙的反驳方法。""这种'转移'……只是形式上的而不是实质上的转移，即并非对论题内容的转移，而是在以曲折的陈述方式揭露对方论题的荒谬。"

**与常识用法的差异**:

≠ 上篇"转移论题"（g10）：同叫"转移"，一个是诡辩错误，一个是合法反驳 — 这是全书最易混淆的一对。 = 区分判据：转移法只做"形式转移"，实质是借题陈述与对方相反的真实论题（"借题而发"）；   例：作家答"从左往右写"；非洲大使答"和你们国家一样，每人死一次"；鲁迅"我有钱，我有发言权"。 = 应用时机：对方问语含倾向/含侮辱/含荒谬前提，正面回答会输。

**为什么下游需要**:

反驳方法选择器的"语言技巧类"武器。教用户：当正面驳斥可能落进对方陷阱时， 可以"形式答问、实质反转"，但必须保留"论题实质未被偷换"的诚实底线，否则退化为诡辩。

### 以矛攻盾  <sub>(下篇·四、以矛攻盾)</sub>

**作者定义**:

"将矛盾着的两方揭示出来，以其矛，攻其盾，使论敌因无法自圆其说而陷入窘境，这就是'以矛攻盾'的方法。"

**与常识用法的差异**:

≠ 成语"自相矛盾/以子之矛攻子之盾"只指指认矛盾。 = 作者把"以矛攻盾"体系化为反驳方法，并按矛盾类型给出两种用法：   ①观点间矛盾 → 把先后言论联系起来"对举"（戈林诬共产党 vs 警察未搜出党证）;   ②观点与事实矛盾 → 对"实"的揭露（许允言行不一），常需诱问策略引出相悖事实（孟子诱问许行）。 = 特殊分支：针对"悖论"（隐者含于现者自身），须先引申再对举（罗素驳"一切由上帝创造"→引出"上帝有起因"）。

**为什么下游需要**:

反驳方法选择器的首选武器（对应言悖/言实悖类诡辩）。 操作步骤可教：①收集对方全部言论②找冲突③并置对举，若冲突在言与行之间则设诱问。

### 二难法  <sub>(下篇·五、二难法)</sub>

**作者定义**:

"对这种论题，可以从两个不同角度进行假定，而后加以引申，导致出论敌无法接受的结论，使论敌陷入无法解脱的进退两难的境地，这种方法，叫做'二难法'。"

**与常识用法的差异**:

≠ 常识"进退两难/两难困境"只在描述困境状态。 = 作者定义为**从论题两端假定分别引申**的反驳武器，且明确三种变体：   ①结论相互抵触（风水：说不吉则我不当为天子，说吉则弟不当战死）；   ②结论相互对应→两不可接受（顾萼遗嘱：神志不清则遗嘱无效，清楚则必有诈）；   ③从两方面导出同一结论（衅钟：死者无知则无用，有知则更糟）。 = 本质是"借对方论题自身的结构，逼出其不可接受的后果"。

**为什么下游需要**:

高段位语言艺术武器库。谈判/辩论中构造"限定式反驳"： 把对手可能的反驳路径预先封死（如审判员对陈某的双设问）。

---

### 剖析  <sub>(下篇·六、剖析)</sub>

**作者定义**:

"对荒谬论题所论及的事物情况，先进行分解，然后就一点或几点分别加以论述，这就是'剖析'。""'剖析'所及是某些方面、某些因素，其最终目的是驳倒整个荒谬论题，就过程而论，是先分后总、先剖后论、分而治之。"

**与常识用法的差异**:

= 作者定义：分而治之——把论题涉及的事物分解成几方面，逐点论述，最终整体驳倒。 = 四种解剖角度（原文）：是非剖析、利害剖析、实质剖析、后果剖析。   - 是非剖析：分解后再判是非（蔡元培"学行有先后，人格总平等"）；   - 利害剖析：分清利与害，纠正以利为害/以害为利（刘少奇论放海匪头子）；   - 实质剖析：剥现象、揭实质（陈赓揭"消极抗日"实质）；   - 后果剖析：揭示荒谬论题导致的后果（普列汉诺夫驳"保俄即保沙皇"）。

**为什么下游需要**:

适用"对方论题涉及复合事物、一刀切断言"的场景。给用户提供"选一面剖面强行突破"的策略， 避免被整体宏大论题唬住（先剖后论，逐个击破）。

---

### 实证  <sub>(下篇·十、实证)</sub>

**作者定义**:

"维诺格拉多夫说：'驳斥对方所提出的论题的最可靠最有效的方法，是用事实来驳斥的方法。'""以事实来驳斥的方法，就是'实证'的方法。""事实泛指各种形式的客观存在，可以是'虚'的，也可以是'实'的。"

**与常识用法的差异**:

≠ 常识/方法论"实证研究"（empirical research）指大样本数据验证。 = 作者限定为**用事实驳斥论题**的反驳方法，且事实分两类：   ①"虚"事实=经验/感受中的事（未必时空确凿，重"合理性"而非真实性，可即兴编撰 — 墨子驳彭轻生子）；   ②"实"事实=真人真事，关键在一个"真"字，须确凿、略引/详引视受众而定。 = 强调"事实本身不会自动反驳"，须被反驳者发现、理解、运用才有作用。

**为什么下游需要**:

反驳方法选择器中"最可靠最有效"的一档。区别于"真相反驳"（专攻歪曲真相类）； 实证告诉你事实可以"虚"着用（编一个合理情形让对方无话可回）。

---

### 归谬  <sub>(下篇·十五、归谬)</sub>

**作者定义**:

"先假设荒谬之说成立，而后，以之为依据，循着'有此必有彼'的关系，引申出一个更为明显荒谬的说法，使人一望而知，使荒谬论题暴露无遗，这就是个'归谬'的过程。""'归谬'是一种间接反驳的方法，因为它是借助引申出的论题来达到反驳目的。"

**与常识用法的差异**:

≠ 常识"归谬法"="假设对方对推出荒谬"（只保留最粗的骨架）。 = 作者系统分层，多种用法：   ①引申兼带否定（反问句、'没听说过'）；   ②只引申不否定，否定留于言外（最常见）；   ③引申出完全虚拟不可能的事实（派山羊为使臣）；   ④引申出已存的公认事实，以相悖揭示荒谬（食红米饭者皆有丧？）；   ⑤**行为归谬**：引申出体现荒谬论题的"行动"来反驳并惩罚对方（范缜烧众香、西门豹投巫婆）。 = 可加深引申（冯玉祥"尚手枪则可杀人"）、可渲染详述（鲁迅防毒面具）。

**为什么下游需要**:

间接反驳的核心武器，也是"语言艺术进阶"skill 的主力。 "行为归谬"是全书写给辩手最有威慑力的一招（用对方理论的自毁性来反制）。

### 以谬治谬  <sub>(下篇·十四、以谬治谬)</sub>

**作者定义**:

"'以谬治谬'是用与论敌同样荒谬的论题去予以回击。""它只是不直接针对论题，而是让论敌切身感受其论题的荒谬。'以谬治谬'重在'治'，不在'驳'，是以'治'达到'驳'的目的。"

**与常识用法的差异**:

≠ 常识"以其人之道还治其人之身/以毒攻毒"（泛指反制）。 = 作者精确定义：用一个**同样荒谬**的论题回击对方，目的不是"驳"论题而是"治"对方 —   让对方切身感受荒谬（大公以无星期限制条件，卢斯杰姆用无日期取马来回敬；阿凡提回敬皇帝"看您有四条腿"）。 = "治"的两层：一为制胜（摆脱困境），二为惩罚（使自作自受）。 = 与"归谬"区别：归谬是顺着对方论题引申出荒谬；以谬治谬是**新造一个平行的荒谬论题**去还治其身；   与"实证""类推"区别：以谬治谬不借助事实，纯用荒谬对荒谬。

**为什么下游需要**:

高压反制武器，适用于对手恶意取笑/设陷阱时。必须搭配伦理提醒： 此手法有以恶制恶色彩，使用需有边界（BOOK_OVERVIEW 批判中也点名该手法缺门槛提示）。
