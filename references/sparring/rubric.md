# 陪练评分卡细则 + 复盘模板

> 陪练幕4/幕5用：AI 判卷与复盘的标准动作。评分必须可追溯（引用能力卡章节），不凭感觉。

## 五维评分（各20分，满分100）

| 维度 | 判什么 | 扣分规则 |
|---|---|---|
| 识别精度 | 是否定位正确手法/预设/陷阱结构 | 手法名说错 -10；说对但理由含糊 -5；识别出但过度（把无关也打成诡辩）-5 |
| 破解正确 | 复杂问语先拆预设否；陷阱是否避开；是否正面踩坑 | 直接踩中预设 -15；拆了预设但没给答案 -5；先拆预设再答 +满分 |
| 武器选择 | 反驳方法对路否（对照反驳类15卡）| 用错武器（如对"歪曲事实"用归谬）但论点仍成立 -8；武器对路 + 满分 |
| 边界纪律 | 有无误伤：正常批评当攻击/过度防御/滥用强武器/转向人身 | 有明显误伤 -10；轻微越界（语气过冲）-5；**误伤对方本人的一次 -15** |
| 表达力 | 说辞是否可直接出口、简洁有力、得体 | 学术腔、说教感 -5；啰嗦无重点 -5；短句有力+可实战 + 满分 |

## 硬性规则

1. **边界纪律是闸门**：出现"把正常批评当人身攻击""辱骂回敬""对无关者以谬治谬" → 本轮总分**封顶60**，其他维度照常给分（让用户看得清哪块好的同时意识到红线）
2. **不双杀**：识别错手法但破解动作对 → 识别维扣分，破解维给分，不因连锁错误惩罚两次
3. **入门难度给提示**：识别维度第一轮卡壳时，判卷前先给一次"提示后补答"机会（提示后答对给 12/20，不提示前满分）
4. **判卷依据**：引用对应能力卡的 E 步骤与 B 边界，判卷文案里带出处（如"对照 concept-identity.md 步骤2：词形没变但所指变了即为偷换"）
5. **用户可免评**：用户说"免评只管练"→ 只给一句点评不细判；说"换判法"→ 重新判

## 训练日志（可选，D3）

- 位置：`books/诡辩与反驳/sparring-log/YYYY-MM-DD.md`
- 每次陪练结束追加一条：日期/场景/难度/手法/得分/复盘要点
- 累计10轮后，输出「错题专项报告」：常错手法Top3、弱项维度、推荐练习组合
- 用户说"记下来/进日志"才记录，不默认记录

## 升级判定

| 当前难度 | 升级条件 | 降级条件 |
|---|---|---|
| 入门 | 连续2轮 ≥85 且边界无扣分 | — |
| 进阶 | 连续2轮 ≥80（隐藏手法全拆对）| 一轮 <60 → 提示回入门 |
| 大师 | 一轮 ≥85（多手法组合+设套全破）| 一轮 <60 → 提示回进阶 |
## 四模式判卷（v1.2.0 新增：五维 80 + 模式四维 40 = 120）

> 触发条件：四模式专训局（P1-P4）或用户指定「按模式判」。

| 维度 | 判什么 | 扣分规则 |
|---|---|---|
| 识别精度（20）| 手法/帽子/潜台词定位 | 同五维规则 |
| 破解正确（20）| 破解动作对不对 | 同五维规则 |
| 武器选择（20）| 技法/武器与模式匹配 | 模式内技法选错 -8，用错模式（如阴阳局用了开怼硬话）-15 |
| 表达力（20）| 是否直接出口、痛辣、得体 | 文绉绉 -5，软绵绵无攻击性 -5，痛辣精准 +满分 |
| **模式匹配度（10）** | 开局报的模式与对手类型是否匹配 | 报错模式 -5；开局模式对但中途乱切 -5 |
| **火力档位（10）** | 升档时机（该升级没升/不该升乱升）| 过度升档（对客气人开怼）-10；该升不升（对方加码还讲理）-5 |
| **越界检测（10）** | 脏字/辱骂家人/造谣/对号入座/翻旧账 | 任一红牌 -10 且本轮总分封顶 80 |
| **收尾时机（10）** | 见效即停、不追击 | 对方服软还追击 -5；补一刀金句定格 +满分 |

**硬性规则补充**：越界检测是闸门——脏字/造谣/辱家任一发生，本轮总分封顶 80，其余维度照常给分。

## 小白快评双轨（v1.4.0 新增）

> 用户说「快评/别打分/一句话点评」或新手场次（前 3 次陪练）→ 走快评轨道，不秀 120 分术语。

**快评模板**（一句话定性 + 一句改进）：
```
✅ 这轮接住了：识别出【手法】，反击用了【技法】，那句【引用】最漂亮。
➡️ 改进：开头少点情绪词（换「您这话可站不住」），火力可以再上一档（用【技法】）。
下一轮难度：×（入门/进阶/大师）
```

**切换规则**：快评 3 次后询问「要不要看完整 120 分判卷」→ 用户点头再切进阶轨道。
