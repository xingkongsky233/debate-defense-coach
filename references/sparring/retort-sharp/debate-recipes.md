# ⚙️ 辩论配方表（v1.3.0 · L4 数据层 · 参数化）

> 触发：「开赛：配方=XX，话题=YY」「预演：配方=XX」
> 用法：一句话开机，自动按配方派遣双 Agent（A方人设/手法序列/B方人设/轮数/火力）

## 配方参数结构

```
配方 = 场景主题 + A方人设 + B方人设 + 手法序列 + 轮数 + 火力档 + 胜负线
```

## 使用示例

```
「开赛：配方=R4扣帽大战，话题=偶像应援该不该管」
「预演：配方=R2职场PUA，我要谈涨薪，预演领导会怎么出招」
「开赛：配方=R3杀猪盘，话题=朋友介绍的高收益理财"
```

## 自定义配方

「开赛：话题=X；A方人设=Y（说Z话术）；B方人设=W；轮数=N（默认5）；火力=全开/中等」
→ 按自定义参数生成，未指定项走默认（R4 模板）。

## 流程（自动执行）

A方生成 N 轮攻击（含扣帽+手法标注）→ B方拿真实招数逐轮回敬（含拆招+技法）→ 裁判 70 分/轮判卷 → 归档 sparring-log/debates/EX-DXX + 学习点 → 更新战法统计。
