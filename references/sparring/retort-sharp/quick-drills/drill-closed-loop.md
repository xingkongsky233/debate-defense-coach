# 🎓 训练闭环机制（v1.5.0 · 任何人可练）

> 触发：「快练 / 练我 / 出题考我 / 训练」｜ 设计目标：小白 5 分钟毕业，老手可刷大师包。

## 一、新人三练（首次使用自动引导，5 分钟）

```
第1练·识别：「他这话什么意思？」+ 模拟对话 → AI 展示手法拆解（看会）
第2练·反击：「帮我怼回去」→ 3 档回法（挑一档照念）
第3练·上手：「来练练」→ 3 轮对打 + 一句话快评（不抛分数）
→ 完成三练 = 发「毕业卡」：已学会 3 招必杀（识别/反击/对打）
```

## 二、训练闭环（练 → 判 → 处方 → 过关 → 晋级）

```
用户选难度（我是新手/有点经验/老手 → 自动出对应包）
   → 逐题 30 秒接招（每题含标准答案+解读，练完对照）
   → 判卷（快评）→ 错题本标记通病
   → 通病触发处方（↓第五节 5 个通用处方）→ 下次开场先练 3 分钟处方
   → 本包过关（入门 70%/进阶 80%/大师 90%）→ 发学习卡集齐进度 → 晋级下一包
```

## 三、学习卡机制（打完必得，零基础也有收获）

```
每打完一题发一张卡：
「本局核心武器：B5 锚原话——把他原话复述出来再聊
  适用：谁扣你帽子/曲解你 ｜ 句式：把我原话一字不差重复一遍，再往下聊
  出处：EX-D09 实战验证」→ 十张卡 = 带走十招
```

学习卡可直接复制进用户笔记（支持「收卡」指令归档到 sparring-log/学习卡集.md）。

## 四、难度自适应

| 用户自述 | 出题包 | 过关线 |
|---------|--------|:------:|
| 我是新手 | 入门包（10 题·单手法）| 70% |
| 有点经验 | 进阶包（10 题·复合连环招）| 80% |
| 老手 | 大师包（10 题·围攻/陷阱链/限速）| 90% |

未自述默认从入门包开始；过关自动提示升包。

## 五、5 个通用处方（任何人练到相关题错都自动开小灶）

| 处方 | 治什么 | 题源 |
|:----:|--------|------|
| 处方1 自证清零 | 对方扣什么你答什么 | 入门包#3#7 + 专属 10 题改写 |
| 处方2 画饼三问 | 画饼零拆解 | 入门包#5 + 专属 5 组（必问名额/标准/节点）|
| 处方3 扣帽三大件 | 打成互扣循环 | 入门包#9 + 专属 5 题（追问/锚原话/举证责任）|
| 处方4 情绪词清零 | 胡搅蛮缠式开头 | 专属 10 句怒火版改写（error-notebook 已含）|
| 处方5 法条锚 | 报法条不报全名 | 进阶包#4 + 专属 5 组（消费/物业/劳动背全名）|

机制：错题本每记一次通病 → 下次陪练/快练开场自动推送：「先练 3 分钟处方X，再开打」。
