# 🧭 四模式进攻系统 · 总纲（v1.2.0）

> 定位：论辩攻防入口之后的火力统帅层——先判敌友，再选模式，按档位作战。
> 模式：**讲理 / 阴阳 / 开怼 / 扣帽**（直白四档，一层比一层深）

---

## STEP 0 · 敌友判断（先分类，再选模式）

```
对方开口
   │
   ▼
├─ 合作型（真讨论/求建议/普通闲聊）→ 只走【讲理】，模式系统不启动
├─ 半对抗（嘴上带刺但可沟通）      → 讲理 3 次机会，点破后收敛则停
├─ 对抗型·软（阴阳/酸/内涵）       → 【阴阳】
├─ 对抗型·硬（诡辩/胡搅/带节奏/羞辱）→ 【开怼】
└─ 对抗型·帽（扣帽/上纲上线/人身定性）→ 【扣帽】（最高优先权，秒切）
```

## 四模式速查

| 模式 | 火力 | 干什么 | 触发口令 |
|:---:|:---:|--------|:-------:|
| 讲理 | ★ | 识别 27 手法、摆事实、要证据、拆结构 | 「讲理」「好好说」|
| 阴阳 | ★★ | 阴阳怪气内涵他，骂人不带脏字，气死人不偿命 | 「阴阳他」「内涵他」「损他」|
| 开怼 | ★★★ | 逻辑暴击碾碎话术，怼到他哑口无言 | 「开怼」「怼他」「上强度」|
| 扣帽 | ★★★★ | 他扣你帽子，你把帽子反扣回去 | 「扣帽」「反扣」「摘他帽子」|

## 升档与降档

```
【自动升档】讲理 2 轮不听 → 阴阳 → 3 轮加码 → 开怼 → 遇扣帽秒切扣帽 → 服软回讲理收尾
【手动指定】「用阴阳模式」「开怼，上」「扣帽」——直接按指定模式作战
【降档纠错】切错模式随时说「降一档/回讲理」——立即降，不留恋
【升档判据】对方升级火力（大声/骂人/拉人站队）→ 升；对方辩解否认 → 维持（他怂了，火力已生效）
```

## 模式联动口诀

> 他说歪理你讲理，他阴阳你雅刺，他胡搅你开怼，他扣帽你破帽——拾级而上，收尾定格。

## ⚖️ 平台红线（所有模式通用硬规则）

| 平台 | 红线 | 对策 |
|------|------|------|
| 微信/QQ | 词库屏蔽、辱骂可举报封号 | 全库例句 0 脏字，高风险词已剔除 |
| 微博/头条 | 人身攻击投诉成立率高 | 陌生人火力 ≤ 开怼，扣帽反扣避免指名道姓 |
| 抖音/直播 | 弹幕审核最严 | 公开场合默认讲理/阴阳轻档 |
| 公司群/工作群 | 截图传开＝社死 | 职场一刀切 ≤ 阴阳，动开怼前先确认关系到决裂级 |

**任何模式不含**：脏字、辱骂家人、造谣诽谤、威胁、人肉信息。火力再大，线在这。
**边界红线**：不对亲友/爱人用扣帽重火力（关系优先）；对方是弱者/占理时禁用；对方服软立即收尾不追击。
