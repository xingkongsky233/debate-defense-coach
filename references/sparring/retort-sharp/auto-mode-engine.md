# 🤖 自动模式识别引擎（v1.3.0 · L1 入口层）

> 触发：「自动判定」「帮我看看该用哪招」「他这话什么意思」+ 粘贴对方原话
> 功能：输入对方原话 → 输出【敌友类型 + 手法定位 + 推荐模式 + 推荐弹药】

## 判定树（按序走，命中即停）

```
STEP 0 敌友判断
   ├─ 正常提问/观点讨论（无攻击信号）→ 讲理模式（全程不动武器）
   ├─ 含阴阳词（"可真厉害/格局真大/不像某些人"等）→ 阴阳模式
   ├─ 含扣帽词（"不爱国/杠精/洗白/收钱/装/玻璃心"等）→ 扣帽模式（最高优先）
   ├─ 含诡辩结构（"大家都/从来如此/你行你上/抛开事实"等）→ 开怼模式
   └─ 含法律威胁（"停水停电/投诉你/赔偿"等）→ 开怼+追证

STEP 1 手法定位（对照词库命中 27手法/38计/帽子分类）
STEP 2 推荐弹药（对照命中手法 → 对应技法卡）
STEP 3 输出格式（见下）
```

## 词库速查（命中词 → 判定）

| 攻击信号 | 原话特征词 | 推荐模式 | 首选弹药 |
|---------|-----------|:-------:|---------|
| 阴阳怪气 | 可真/真好/不像/厉害了啊/格局 | 阴阳 | S4 翻话直译 / S5 镜像 |
| 扣帽子 | 不爱国/洗白/杠精/收钱/装/玻璃心/想红 | 扣帽 | B1 追问具体化 / B5 锚原话 |
| 诡辩 | 大家都/从来如此/你行你上/抛开事实/你也一样 | 开怼 | H5 以矛攻盾 / H6 追证 |
| 道德绑架 | 良心/白养你/为你好/付出这么多 | 扣帽 | B2 换帽 / H5 您当年 |
| 伪权威 | 专家说/研究显示/大家都信 | 开怼 | H6 追证三连 |
| 两头堵 | 怎么都是错/转也错不转也错 | 开怼 | H4 不入局 |
| 情感勒索 | 眼泪/求你了/就这一次 | 扣帽 | B3 升维 / 给第三条路 |
| 威胁 | 停水停电/投诉/你等着 | 开怼 | 法条锚+录音 |
| 诉诸传统 | 老祖宗/我们当年/从来如此 | 阴阳/开怼 | S6 借古讽今 / 时代变量 |
| 定义战 | 这叫XX吗/你也配叫XX | 开怼 | B3 定义权争夺 |

## 输出格式（引擎答模板）

```
【敌友】对抗型·帽
【手法】扣帽子（立场帽：不爱国论）
【推荐模式】扣帽模式（M4）
【推荐弹药】B1 追问具体化 → B5 锚原话 → B6 定帽
【出口句】「您说的具体是哪件事？哪句话让您有这感觉？」
【升级提示】若对方 3 轮持续扣帽 → 直接 B6 定帽收网
```

## 边界

- 引擎只做判定与推荐，不替用户开口；用户可改判（「不是扣帽，直接开怼」）
- 拿不准时输出「倾向+备选」两套方案，宁降勿升（对熟人误判成本高）
