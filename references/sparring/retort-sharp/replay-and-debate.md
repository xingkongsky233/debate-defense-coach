# 🎮 实战复盘机 + 双 Agent 自动辩论赛（v1.2.0）

> 三件套闭环：观战学招（自动辩论赛）→ 上场练习（陪练局）→ 复盘纠错（实战复盘机）

---

## 模块 A：实战复盘机（赛后录像分析室）

**触发口令**：「复盘这段」「帮我看看刚才哪里没接住」+ 粘贴真实对话/截图文字

**流程**：
```
输入：一段真实吵架记录（或多句复述"对方说了X，我当时没接住"）
  ① 逐句解析：对方每句话用了什么手法（27 手法/38 计/帽子/隐蔽攻击/流氓逻辑）
  ② 关键时刻标注：⚠️ 这里该切「阴阳」/ 🚨 这里该用破帽 B5 锚原话 / 💡 这里该升档
  ③ 原话重写：你的每句回话给出「如果重来」痛辣版改写（对应模式）
  ④ 错题本：自动统计丢分项（「你在动机帽前总掉线」→ 推荐对应陪练局）
输出：复盘报告 + 错题本更新 + 推荐陪练局点单
```

**错题本机制**：每次复盘追加一条记录（场景/掉线模式/丢分项），累计 3 次同类型失误 → 主动提示「这个坑你已经丢了 3 次，建议开 X 局专练」。

## 模块 B：双 Agent 自动辩论赛（自动观战/学习器）

**触发口令**：「开赛：话题=XXX」/「让它俩辩一场」/「帮我预演一下别人会怎么怼我的观点」

**流程设计**：
```
① 立题：内置话题库 topics.md 选一个，或用户自定义（「话题=XX 观点」）
② 派遣双 Agent（各配独立提示词，互不可见对方的任务）：
   - 正方 Agent：立场=支持话题；工具=四模式全库（讲理为主，3 轮后可加火力）；
     每轮先拆对方手法再立论；任务=赢
   - 反方 Agent：立场=反对话题；人设=难缠对手；工具=叔本华38计+杠精24谬误+帽子分类学；
     每轮换 1-2 种手法（不许重复）；任务=难倒正方
③ 对局规则：3 轮正反辩论 + 1 轮自由辩论（快问快答，每方限 3 句）
④ 主系统当裁判：每轮后判卷（双方手法识别/逻辑漏洞/火力档位/越界检测）
⑤ 输出：全程实录 + 裁判点评 + 「观众学习点」清单（这场能学到什么手法与破法）
产物：归档 sparring-log/debates/ + 学习点进错题本/陪练建议
```

### 双 Agent 提示词模板

**正方提示词（发给 Agent A）**：
```
你是论辩赛正方辩手。立场：支持「话题」。
规则：① 每轮先识别对方上一轮使用的手法（查 references/sparring/retort-sharp/ 全库），
指出后再立论 ② 论点必须有事实/数据/逻辑支撑，禁止编造 ③ 前 3 轮只用「讲理」火力，
对方先耍流氓后可升级（阴阳→开怼→扣帽）④ 全程 0 脏字 ⑤ 每轮 150 字以内。
目标：赢得这场辩论。
```

**反方提示词（发给 Agent B，用作"陪练靶子"）**：
```
你是论辩赛反方辩手。立场：反对「话题」。人设：难缠的对手。
规则：① 每轮从叔本华38计/杠精24谬误/帽子分类学中选 1-2 种手法使用（不许连续重复），
手法要藏进话里不让对方一眼看出 ② 可扣帽子、上纲上线、偷换概念，
但禁止脏字和人身辱骂 ③ 每轮 150 字以内 ④ 对方拆穿你的手法后，下一轮必须"换招"
（体现真实杠精的变色龙行为）。
目标：想尽办法让正方难受。
```

### 裁判判卷（主系统每轮执行）
| 维度 | 分值 |
|------|:---:|
| 手法使用/识别（反方用了几种、正方拆了几种）| 20 |
| 逻辑漏洞（谁的话有破绽）| 20 |
| 火力档位匹配（该升级时升没升）| 10 |
| 越界检测（脏字/造谣/人身辱骂红牌）| 10 |
| 表达力（话说得清不清楚、狠不狠）| 10 |
| **每轮合计** | **70** |
