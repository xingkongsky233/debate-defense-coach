# 对手话术库（27种手法 × 现代场景例句）

> 陪练幕2用：AI 按选定手法从本库取句出招（可跨库组合）。例句为书中案例的现代迁移，口语化。
> 难度标注：【入】入门可直给手法提示 ｜【进】进阶隐藏手法 ｜【大】大师可组合。

## 概念类

**1. 偷换概念**
- 【入】理发现："烫头嘛，怎么能不烫呢？"（把"烫发"换成"烫伤"）→ 销售："我们说的'免费'是免费试用，不是免费拥有。"
- 【进】"你说的'负责任'是不出问题，我说的是出了事有人扛，两个意思你别混。"
- 【大】辩论中："你刚才说的'公平'是结果公平，我们讨论的是机会公平。"（同一词两概念来回切）

**2. 四概念（三段论中项偷换）**
- 【进】"中国人都是勤劳的，你是中国人，所以你应该任劳任怨。"（总体→个体）
- 【入】"书是知识的海洋，这本小册子是书，所以它是知识的海洋。"
- 【大】"一遍遍刷题就能提分——题海战术适合所有人。"（"刷题"范围暗中扩大）

**3. 混淆概念**
- 【进】"你这是'提意见'还是'抱怨'？提意见我们欢迎，抱怨就是态度问题。"（把概念揉成对自己有利的二分）
- 【入】会议室："我们说的'预算'是一回事，你说的'成本'是另一回事，别混为一谈。"（不定义就各说各话）
- 【大】"你这不是'坚持原则'，是'固执己见'。"（同一行为换标签定性）

## 论题类

**4. 偷换论题**
- 【进】"你刚刚不是说'不一定能完成'吗？现在怎么变成'你说我完不成'了？"（近似替换）
- 【入】"你说'可以吃'那就是能吃掉它。"（歧义引新义）
- 【大】"你承认了错误作风——那这个项目就是你搞砸的。"（从"作风问题"滑到"项目归因"）

**5. 转移论题**
- 【进】"先别谈加班费，咱们谈谈你这个月的考勤……"（自身漂移）
- 【入】"问我？你怎么不问问你自己去年欠的那几件事？"（反问转移）
- 【大】"说工资低？那你看看现在就业形势，有工作就不错了。"（偷换评价标准）

**6. 言悖**
- 【进】"我从来不情绪化！你这么说我真的很生气。"（断言与态度矛盾）
- 【入】"我们公司最重视的就是人才——除了今年裁员名单上的那些。"（一显一隐）
- 【大】"这个方案两全其美，没有任何缺点——当然，除了成本有点高、工期有点长。"（自相矛盾露头）

**7. 言实悖**
- 【进】"这包绝对是最新款！——当然，上架前在仓库放了两三个月。"（判定vs陈述）
- 【入】"我工作非常认真——这个月就迟到三次，那是我对工作'有自己的节奏'。"（细节自曝反差）
- 【大】"我从不乱花钱——这台手机贵是贵，但它是'投资'。"（用词翻新旧陈述）

## 语言语境类

**8. 以言乱实**
- 【入】"这不叫偷，这叫'借用'——用完了不就还了？"（换词抹平事实）
- 【进】"我们不是涨价，是'价格优化'。"（措辞掩盖实质）
- 【大】"合同写的是'尽可能周五交付'，所以周三交不了也不违约。"（钻文字空子）

**9. 歪曲语境**
- 【入】"食堂天天就这几样菜？——怎么不能选，你可以吃也可以不吃。"（扩大范围）
- 【进】"你问最不爱学习的学生？当然是老师啊。"（偷换物的类）
- 【大】"我说'原则上同意'——原则以外的情况当然不同意。"（自设新语境）

**10. 复杂问语**
- 【入】"你什么时候开始摸鱼的？"（预设：你摸鱼了）
- 【进】"你上次说'考虑一下'，是不是早就决定不来了？"（连环+预设）
- 【大】"我们换个话题聊聊你最近状态——说真的，你是不是已经不打算在这个团队干下去了？"（先耗注意力再收网，检察官式）

## 论据类

**11. 恶性循环**
- 【入】"这药有效，因为它就是这个疗效。"（同语反复）
- 【进】"你是对的，因为我说的都是对的；我说的当然对，因为你是错的。"（循环论证）
- 【大】"他能胜任，因为老板信任他；老板信任他，因为他能胜任。"（长链闭环）

**12. 先验理由**
- 【进】"一看就知道这人不靠谱——长那样能靠谱吗？"（先定论再找证据）
- 【入】"我吃了三十年盐，这菜就该这么做。"（个人经验当真理）
- 【大】"他就是那种人，你们都被他骗了。"（结论先行，证人证词全往结论上靠）

**13. 以偏概全**
- 【入】"我认识两个XX地方的人都不靠谱，所以XX地方的人都这样。"（样本2→全体）
- 【进】"现在的年轻人就是吃不了苦。"（单例/刻板印象）
- 【大】"数据显示我们满意度98%——剩下2%的投诉当然可以忽略。"（筛选式事实）

**14. 谬论为据**
- 【进】"根据吸引力法则，你倒霉是因为你心里想的都是倒霉事。"（伪理论作据）
- 【入】"老祖宗传下来的说法还能有错？"（传统=真理）
- 【大】"专家都说'以形补形'，你该多吃核桃。"（捏造理论/曲解权威）

**15. 假象为据**
- 【入】"我听说他们项目组都在偷偷加班，就你们准点走。"（捏造"事实"）
- 【进】"这数据可是精确到小数点后两位的，还能有假？"（数字假象）
- 【大】"有人看见你去过现场。"（"莫须有"式——谁？什么时候？都不说）

**16. 无关推论**
- 【入】"他爸是开公司的，他肯定也有商业头脑。"（出身→能力）
- 【进】"他连车都买不起，怎么可能是这个项目的负责人？"（消费→职级）
- 【大】"她天天发朋友圈晒加班，工作肯定认真。"（表象→本质）

**17. 或然推论**
- 【进】"下雨天买伞的人肯定都急用——你买伞回去肯定撑过。"（可能→必然）
- 【入】"他最近总加班，肯定是在忙新项目。"（或然→断言）
- 【大】"流程走了这么多道检查，肯定不会出错。"（制度完善=结果必然）

**18. 强为因果**
- 【入】"我昨天说完"要注意身体"，你今天感冒了——就是我给你话说出来的。"（先后=因果）
- 【进】"市场一跌你就卖，市场就是被你们这些人卖跌的。"（个别→全局因果）
- 【大】"他一来公司业绩就下滑，肯定是他带来的霉运。"（相关性→因果）

## 权威情感类

**19. 滥用权威**
- 【进】"这可是XX教授说的，你比教授还懂？"（名字压人）
- 【入】"专家都推荐这个方案，别质疑了。"（权威替代论证）
- 【大】"我说不行就是不行，这个项目我说了算。"（以我为权威）

**20. 以情代证**
- 【入】"想想你父母多辛苦，你还好意思要年终奖？"（诉诸怜悯/愧疚）
- 【进】"全家都盼着你考上，你可不能辜负他们。"（情感绑架）
- 【大】"你看看这孩子的眼神，多可怜——你就原谅他这一次吧。"（悲情营销）

**21. 庸俗类推**
- 【进】"公司像大家庭，你在家会跟家人谈钱吗？"（现象相似硬推）
- 【入】"树挪死人挪活，你辞职肯定没错。"（俗语类推）
- 【大】"打仗都要服从军令，公司决策凭什么不听？"（跨领域硬套）

**22. 乱喻**
- 【进】"人生就像马拉松，起跑慢的注定追不上。"（形象相似非原理相似）
- 【入】"管理公司跟带孩子一样，听话的就是好孩子。"（比喻代替论证）
- 【大】"市场就像潮水，涨潮时猪都会飞——问题是你是猪吗？"（同一喻体双刃）

**23. 强词夺理**
- 【入】"我迟到了？——反正最后事情做完了，你管我几点来。"（文过饰非）
- 【进】"你买的乌龟百年寿命——它今年正好一百岁。"（诡辩性解释）
- 【大】"这不能怪我，要怪就怪地球引力让文件掉错了文件夹。"（荒诞理由覆盖事实）

## 人身类

**24. 无端攻击**
- 【入】"你们团队做事就是不靠谱，每次都掉链子。"（无据指斥）
- 【进】"你这种爱较真的人，到哪都不受欢迎。"（性格攻击）
- 【大】"你连这都想不到？也难怪你们部门一直垫底。"（连带羞辱）

**25. 中伤人身**
- 【入】"别听他说话，他一个中专生懂什么？"（出身攻击）
- 【进】"你去年那个项目就搞砸过，这次你说话没分量。"（翻旧账）
- 【大】"你最近是不是家庭出了问题？脾气这么差，难怪方案被否。"（动机/私生活诛心）

**26. 以谬治谬（对手用）——陪练专用反制演练**
- 【进】"你嫌我说话难听？那你别做难看的事啊。"（双标回旋）
- 【大】"按你的逻辑，你妈妈生你也是想让我生气。"（同构回套）
- 【入】"就你会讲道理？你要是讲道理，猪都会上树。"（低配版，作识别练习用）

**27. 转移法（对手用）——陪练专用反制演练**
- 【进】"你问我们服务怎么样？——先说说你家门口的路修了吗？"（答非所问借题）
- 【大】记者式："请问您对贵公司偷税传闻怎么看？"（预设罪名提问——练拆预设）
- 【入】"你工资多少？——你问这个是不是想借钱？"（反将一军）

## 组合出招（大师难度）

- 先以情代证铺垫情绪 → 趁热下复杂问语（"你是不是不想干了"）→ 贴标签（"你就是矫情"）→ 翻旧账收尾
- 以偏概全立论 → 混入强为因果 → 被识破即转移论题 → 最后中伤人身退场
- 大师难度允许"被拆穿后换手法继续进攻"（模拟真人诡辩者的灵活）

> 纪律：所有例句只用作陪练对手的"靶子"，AI 绝不在技能说明中示范如何主动骗人。
